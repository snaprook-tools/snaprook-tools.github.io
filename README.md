# Snaprook Tools website

Static source for https://snaprook-tools.github.io/, the publisher site of Snaprook Tools, a studio byline making small Unity editor tools.

- Plain HTML and one stylesheet (`style.css`). No JavaScript, no analytics, no trackers, no cookies, no external fonts or CDNs.
- `.nojekyll` makes GitHub Pages serve the files as they are.
- Update `changelog.html` and the Tools section with every release.

Made with AI help. The logo is AI generated. The original file in `assets/logo.jpg` keeps its C2PA provenance data.

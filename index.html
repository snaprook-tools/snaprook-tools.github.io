Small, focused editor tools for Unity

Snaprook Tools is a small studio byline making editor extensions for Unity developers. Each tool does one job well and stays out of your way.

How we work

  • Focused. One tool, one real problem, clear menus and tooltips.
  • Tested. Every tool is tested headless on every Unity version it supports.
  • Respectful. No telemetry, no data collection, no license checks.
  • Made with AI help. Code and text are written with AI assistance, then tested and reviewed before release.
